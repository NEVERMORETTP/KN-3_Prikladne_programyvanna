# Датчики температури (Варіант 11)

## Призначення
Консольний застосунок для агрегації та аналізу показників температури і вологості з датчиків у різних кімнатах, виявлення аномальних температурних коливань та отримання статистичних звітів.

## Запуск
Для запуску програми виконайте команду:
`python variants/lab_11.py`

## Приклад діалогу
> Введіть команду: report
> Результат:
Звіт за кімнатами:
Кімната Кухня: записів 2, сер. темп. 29.25, макс. темп. 36.00, аномалій 1
Кімната Спальня: записів 1, сер. темп. 21.00, макс. темп. 21.00, аномалій 0
Підсумковий рядок:
Всього записів: 3

> Введіть команду: top 2
> Результат:
1. S03: 36.00
2. S01: 22.50

> Введіть команду: unique
> Результат: Кухня, Спальня

> Введіть команду: exit
> Результат: (програма завершує роботу)
